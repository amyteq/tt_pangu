## GitHub agent rules

- **Issue Triage Agent** may read issues / comments and update labels /
  comments only when the rule is deterministic.
- **Issue Triage Agent** must not infer decisions from ambiguous
  comments.
- **Implementation Agent** may work only when the issue has `ai:ready`,
  required decisions are `decision:confirmed`, and acceptance criteria
  are clear.
- **Milestone Reviewer** may create follow-up issues but must not claim
  readiness without tests / evidence.
- **Release Readiness Agent** may summarize blockers but must not grant
  READY.
- **Test Coverage Reviewer** may create test-gap issues or propose test
  PRs; implementation requires approval.

## Permissions

- Local edits and local tests are allowed.
- GitHub read operations are allowed:
  - `gh issue list / view`
  - `gh pr view`
  - `gh label list`
- GitHub write operations require explicit human approval:
  - `gh issue edit / comment`
  - `gh pr comment / edit`
  - `gh label create / edit / delete`
  - `gh pr create / merge`
- `git commit` and `git push` require explicit human approval.
