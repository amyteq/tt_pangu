# Orbit model card: 20260617-cs-local20 (+ 20260617-vm-local20 value head)

> **First training cycle = plumbing proof-of-life on LOCAL self-play, not a strength claim.**
> Offline metrics here measure imitation of *local agents* and must not be read as ladder strength.
> Promotion is gated on an arena A/B (VALIDATION.md #3), not on these numbers (see Risks).

## Purpose

- **candidate scorer** (`20260617-cs-local20`) — ranks engine-legal candidate launches by
  `P(teacher launched this)`. Re-orders a FlightOracle-validated candidate set; never emits angles.
- **value model** (`20260617-vm-local20`) — regresses realized future score delta (h50), an
  *outcome* label for tie-breaking / high-value preference. Trained this cycle; **not exported**
  (Pearson r 0.68 on local data is not strong enough to promote).

## Training data

- replay corpus: **LOCAL self/cross-play** generated by `datasets/gen_local_episodes.py` — NOT
  ladder replays. Agents: kuni05 (~1240), evogen1093 (~1093), v4, v3.2, pub_tactical.
- date range: generated 2026-06-17 (seeds 7000–7003).
- number of episodes: 20 (16× 2p pairings + 4× 4p FFA).
- 2p/4p split: 16 / 4 episodes; candidate rows 2p-heavy (4p has more planets → more candidates/step).
- top-player filter: none (local agents; `top_player_episodes=0` — there is no ladder-rating signal).
- train/valid/test split: episode-split 75/25 (no step or episode leakage); no separate test split
  this cycle (small corpus). `n_train=102450 / n_valid=41828` candidates.
- leakage prevention: split by `episode_id`; FlightOracle labels are deterministic from board state.

## Features

24 features, shared `models/_featurize.py` `FEATURES` contract (exported with the npz):

- planet-pair features: `tgt_strategic_value, tgt_roi, tgt_holdability, tgt_pressure, tgt_frontier,
  tgt_centrality, tgt_is_comet, tgt_reinforcement_need, tgt_threat_window, tgt_owner_is_enemy/neutral`.
- ledger / path features (FlightOracle): `path_valid, path_eta, path_min_sun_distance, path_near_sun,
  path_first_hit_is_target`.
- global/player features: `remaining_steps, phase, src_ships, src_defense_slack, src_is_hub,
  src_is_safe_bank, ships, ship_bucket`.
- short history features: **none yet** (v0; flagged for v1).
- 4p features: implicit via owner flags + per-seat battlefield state; no explicit 4p one-hot yet.

## Labels

- imitation: `teacher_selected` ∈ {0,1} — did the seat's agent actually launch this (src → first-hit
  target, via FlightOracle decode). Positive rate **0.37%** (539 / 144278; 469 decision points).
- value: `future_value_delta_h50` (realized Δscore 50 steps ahead) — value-model target.
- safety: candidates carry FlightOracle `oracle_valid / oracle_first_hit_type / min_sun_distance`;
  unsafe (sun/oob) candidates are *features*, not silently dropped (the rule engine/sanitizer act).
- outcome: `terminal_outcome` (seat final reward) recorded per row; unused this cycle.

## Model

- architecture: MLP `24 → 128 → 64 → 1` (ReLU hidden), sigmoid (scorer) / linear (value).
- framework: PyTorch 2.12.0+cpu (training only). ~12k params.
- parameters / export format: scorer → `scorer.npz` (97 KB) = weights + standardization mean/std +
  FEATURES order. `export_npz.forward()` is the reference **pure-numpy** forward.
- online runtime: ladder agent loads the npz with **numpy only** (no torch import). Self-check:
  numpy forward reproduces torch to `max_err = 0.0` over random inputs. p99 inference: a 24-dim MLP
  over ≤~60 candidates/step is sub-millisecond (matrix mult of ~60×24); well within the 1000ms/turn
  budget — to be re-measured in-agent at prompt 06 integration.

## Metrics (offline, held-out episodes)

Candidate scorer (`20260617-cs-local20`):

- validation ranking AUC: **0.922** (2p **0.936** / 4p **0.903**).
- recall@k vs teacher: @1 **0.282**, @3 **0.502**, @5 **0.626** (over 469 decision points).
- pure-numpy eval over full set (deployed path): AUC 0.920, recall@5 0.615 — matches torch.
- safety false-negative rate: n/a this cycle (scorer does not gate safety; FlightOracle does).
- local arena result: **not run** (no agent integration yet — that is prompt 06).

Value model (`20260617-vm-local20`):

- valid Pearson r (Δscore_h50): **0.683**; normalized valid MSE 1.87 (> train 0.73 → some overfit
  on 20 episodes). Real but noisy; needs the full corpus before it is useful.
- calibration by phase: not yet broken out (v1 TODO).

## Integration

- agent version: **none yet.** Heads are offline-only this cycle.
- fallback behavior: if `scorer.npz` fails to load, the agent runs rules-only (FlightOracle +
  RuleEngine) — the model is strictly additive over the existing deterministic core.
- rule-engine guardrails: model only *re-orders* candidates the RuleEngine/FlightOracle already
  deem legal; it cannot select an unsafe launch.
- FlightOracle gate: final emission still passes `core.action_sanitizer` (VALIDATION.md #7).

## Risks

- **distribution shift (PRIMARY).** Two stacked shifts: (1) classic BC self-induced-state shift —
  T12's BC student hit recall@k 0.387 yet **0% arena**; high offline recall is *not* strength;
  (2) the teacher here is *local self-play*, not ladder players, so even the imitation target is
  off-distribution from the real strong-tier opponents we must beat. **Do not promote on offline
  metrics. Gate on arena A/B (≥+7pt, VALIDATION.md #3).**
- 2p/4p mismatch: 4p AUC (0.903) trails 2p (0.936); only 4 4p episodes — thin.
- runtime: tiny model; low risk, but confirm in-agent p99 at integration.
- overfitting to top-player episodes: inverted here — there are *no* top-player episodes; the corpus
  is small (20) and self-play, so it likely under-represents real strong-tier tactics.

## Decision

**needs more data** before any promotion, but the *infrastructure is GO*. Recommendation:

1. Build the real ladder-teacher corpus on snorlax (full replays, top-player filter) and re-run —
   the local 20-episode run only proves the pipeline trains, exports, and runs in numpy.
2. Proceed to prompt 06 (hybrid integration) to wire the scorer **behind** the FlightOracle/RuleEngine
   as an additive re-ranker, then judge it ONLY by arena A/B — not by the AUC above.
3. Defer the value model until the full corpus (current r=0.68 is promising but data-starved).
