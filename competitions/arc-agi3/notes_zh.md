## 一、这个比赛到底是什么(一句话 + 一段话)

**一句话:** ARC-AGI-3 是 ARC 系列里**第一个"交互式 / 智能体"基准**——不再是看输入网格猜输出网格,
而是**让 agent 去玩 135 个没有说明书的回合制小游戏**。

**一段话:** 每个环境是一个 64×64、16 色的网格小游戏,**没有规则、没有目标、没有示例**。agent 只能
通过**不断行动→观察反馈**来:① 探索发现机制,② 在脑中建立世界模型,③ 自己推断"赢"是什么,
④ 规划并高效执行。评分用 **RHAE**(人类动作数 / agent 动作数)的**平方**,所以"乱探索"会被**平方级
惩罚**。动作只有 ≤7 个(`ACTION1–5` 普通动作、`ACTION6` 是点 (x,y) 坐标、`ACTION7` 是撤销)。
数据切分:**25 公开 / 55 半私有(打榜)/ 55 全私有(终评)**。

### 和 ARC-AGI-1 / 2 的根本区别(这点最重要)

| 维度 | ARC-AGI-1/2(2019/2025) | **ARC-AGI-3(2026)** |
|---|---|---|
| 形态 | 静态"输入网格→输出网格" | **交互式回合制游戏** |
| 交互 | 离线,一次给出答案 | **在线,连续行动+观察** |
| 公开:私有 | ~10:1 | **倒置——25 公开 vs 110 私有** |
| 上线时 AI 最高分 | 个位数% | **< 1%** |
| 主要弱点 | 记忆 / 测试时算力堆叠 | 交互式**几乎堵死了堆算力的路** |
| 数据格式 | JSON 网格对 | **每回合一帧 64×64×16色 JSON** |

为什么交互很关键:AGI-1/2 最后都被"测试时训练 + 堆算力"刷到 50~90%+;AGI-3 让**离线预计算失效**
(不真玩就预测不了下一帧),再用**倒置的公开/私有比例**(只有 18.5% 公开)堵死对公开集的过拟合。

RL/智能体研究,而不是套现成配方。**

## 三、评分机制 RHAE(决定一切策略)

`单关得分 = min(1.0, (人类动作数 / agent动作数)²)`;单游戏 = 各关加权平均(后面的关权重更大);
总分 = 所有游戏平均。**平方意味着:你比人类多花一倍动作,得分不是 0.5 而是 0.25。**
人类基线 = 受控线下实验的"上中位首跑"成绩。**关键利好:agent 内部的"思考步数"不算动作,只有真正
改变环境状态的动作才算**——也就是"想"免费,"做"才计费。

## 六、我认为的核心挑战(7 条)

1. **没说明书、没目标、没示例对。** 这是和 AGI-1/2 最大的断裂——所有"示例对"技术(TTT、程序合成、
   DSL 搜索)全部失效。前沿大模型 < 0.5% 就是因为它们会"推理"但不会"探索+建模"。
2. **探索是平方级昂贵的。** RHAE 平方惩罚,随便乱试 = 自杀。必须**信息贪婪地探索**(每个动作都要最大
   程度降低对世界模型的不确定性)。
3. **泛化悬崖。** 12.58%→0.25%。只有 25 个公开环境(18.5%),任何记住公开环境的做法到私有集就崩。
4. **评测无网络 ⇒ 推理时不能用在线大模型。** 任何 LLM 推理必须在 notebook 里离线跑(离线权重、<12h、
   $10k 上限);前沿 API 只能当**开发期工具**。
5. **长交互上下文。** 多回合 × 64×64 帧 → 历史爆炸,需要选择性检索/压缩(Duke 思路)。
6. **两个榜单要先选。** Official 禁 harness、Community 允许,二者技术栈完全不同,选错就白做(见 `strategy.md` D001)。
7. **最优解未知 + 高方差。** 这是机会也是风险:没有现成配方可抄,要做真研究。

## 七、我的 ideas / 提分技术菜单(详见 `strategy.md`)

**先把"能测量"立起来,再谈聪明的模型。** 当前 AI < 0.5%,一个"能跑通的 SDK 循环 + 本地 RHAE 指标 +
非随机探索基线"就已经超过这个领域绝大多数选手,并且给后面一切实验提供测量底座。

提分技术(按 EV 粗排):
- **信息贪婪 / 好奇心探索**:用世界模型的预测误差作内在奖励,往"模型最不确定"的地方探索——直接对准 RHAE 效率。
- **基于模型的 RL(model-based RL)**:学一个"(帧, 动作)→下一帧"的世界模型 + 规划器(MCTS / MuZero 风
   格 / shooting)。无头 1–2k FPS 让自博弈可行。StochasticGoose 是唯一有非零成绩的路线,看好这条。
- **对象中心感知前端**:把 64×64 网格切成"物体"(Core-Knowledge 先验)→ 紧凑状态 → 更小更易泛化的策略
   /世界模型。**这块和 AGI-2 共用**。
- **元 RL / 关内快速适应(in-episode adaptation)**:RL² / 快权重 / 测试时策略更新,让 agent**当场学会**
   每个新游戏——这正是基准要考的能力,也是对抗泛化悬崖的正解(比"逐环境训练"强)。
- **分层 RL / 技能发现**:为后期组合关学习"把物体移到某区域"之类的可复用 option。
- **目标推断**:赢下教程关时观察"什么变了"→ 假设目标 → 在后续关里追求它(主动 goal-setting 是 4 大考点之一)。
- **社区赛道的智能体 harness**:编排器 + 子智能体 + 压缩记忆 + 选择性历史(Arcgentica + Duke),套在
   **离线开源权重**推理器外面。
- **撤销 ACTION7 当便宜回滚**:激进探索 + 撤回死路;但要先确认撤销算不算动作(⚠ 算的话就不"免费")。
- **程序化课程 / 自博弈**:对 25 个公开环境做变体增强,练出稳健先验而不过拟合那 25 个具体游戏。

**要避开的坑:** 直接搬 AGI-2 那套(TTT/程序合成/DSL)→ 约等于 0 分;把在线 LLM API 当提交方案(评测
无网络);过拟合 25 个公开环境(经典死法);把"随机/暴力探索"当策略(被 RHAE 平方惩罚)。

## 八、和 ARC-AGI-2 能互相借鉴吗?(你的问题,完整答案见 `cross-competition.md`)

**结论:能借的是"工具箱 + 大脑",不能借的是"解题核心"。** 两赛共享领域(彩色网格)和哲学(考效率、
考泛化不考记忆),但**算法层几乎不通用**——AGI-2 是"从示例对一次性归纳规律",AGI-3 是"多回合 POMDP /
探索"。

**不能借(AGI-2 的看家本领在 AGI-3 全废):** TTT、程序合成、DSL 搜索、转导+归纳集成、增强投票选择——
全部依赖示例对,AGI-3 没有。**直接照搬会得 0 分**,这正是前沿模型卡在 0.5% 的原因。

**能借(共建一次、两边都用):**
1. **网格库 `lib/grid.py`**:解析/编码/差分/对称旋转/渲染(尺寸参数化:AGI-2 是 30×30 整数,AGI-3 是
   64×64×16色)。两赛的 Core-Knowledge 先验(物体性、对称、拓扑、物理)**完全一致**。
2. **Kaggle 离线打包工具**:复用 nemo 的 `kca-<slug>.yaml` + 即时生成 metadata + 扁平 `kernels/`+`lib/`
   + <12h 守卫 + 离线 wheels(含 Blackwell vLLM 离线配方)。两赛都是"无网络 Kaggle notebook"。
3. **本地评测纪律**:都要**本地指标**省每日配额——AGI-2 用像素匹配(参考 nemo `eval/official_metric.py`),
   AGI-3 用 25 公开环境的本地 RHAE。共享铁律:**离线 gate 必须对齐线上指标**(nemo 教训 INS-006)。
4. **RL / GRPO 脚手架**:我们 nemo 后赛已设计过"可验证奖励 GRPO"。AGI-3 本身就是 RL 问题;AGI-2 也能用
   RLVR 做答案匹配。共享验证器 + rollout 管线。
5. **Core-Knowledge 先验检测器**:物体分割、对称检测、包含/拓扑、简单物理——两边都能当感知前端。

**借的方向:**
- AGI-2 → AGI-3:合成数据纪律、增强思维(用作世界模型/帧预测器的数据增强)、成本效率反射、GRPO 设计、网格工具。
- AGI-3 → AGI-2:智能体式精炼循环 + **主动**候选选择(把 AGI-2 解题当成一个短探索回合:提出规则→在留出
  示例对上验证→精炼)。Imbue 的"代码进化"(种群+LLM 变异+适应度)正是把智能体思维搬进 AGI-2,目前是其 SOTA。

**我的建议:** 解题核心保持**两套独立栈**(强行统一会两头都拖垮);**共享工具箱**放进已存在的
`competitions/_shared/`;**共享大脑**(把洞见交叉发到 `_shared/insights.md`)。**精力分配按 EV**:AGI-2 有
*已知*的夺冠配方(TTT+合成+集成,Kaggle SOTA 24%),和我们 nemo 经验直接对得上,近期 EV 更高;AGI-3
**完全敞开**(AI<0.5%),方差大、天花板高、回报偏向 RL/智能体研发,是更长线的赌注。
