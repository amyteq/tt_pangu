有。我的建议是分两类处理：

**最佳方案：不要从 `claude logs <session-id>` 的终端输出转 Markdown，而是从 Claude Code 的 transcript JSONL 生成干净 Markdown。**
`claude logs <id>` 官方定位只是“print recent output from a background session”，也就是终端近期输出，不是干净的 Markdown export。([Claude Code][1]) 你贴出来的 `[2C`、`[1B`、`[19G` 这类不仅是颜色码，还包括 cursor movement；简单 strip 之后有时仍会出现断词、列对齐错乱。

## 方案 A：推荐，用 `claude-code-log` 直接从 transcript 生成 Markdown

`claude-code-log` 是专门把 Claude Code transcript JSONL 转成 readable HTML / Markdown 的工具；它支持整个 `~/.claude/projects/`、单个 transcript、项目目录，并有 `--format md`、`--detail`、`--compact` 等模式。([GitHub][2])

安装/直接运行：

```bash
uvx claude-code-log@latest --tui
```

在 TUI 里选 session，然后按：

```text
m  生成 Markdown
h  生成 HTML
v  在内置 viewer 看 Markdown
```

也可以直接命令行生成：

```bash
uvx claude-code-log@latest \
  ~/.claude/projects/path-to-project/<session-id>.jsonl \
  --detail low \
  --format md \
  --compact \
  -o session-clean.md
```

如果不知道 transcript 在哪：

```bash
SESSION_ID="你的完整 session id"

find ~/.claude/projects -name "${SESSION_ID}.jsonl" -print
```

或者先从 agent 列表拿 session id：

```bash
claude agents --json | jq -r '.[] | [.sessionId, .name, .status, .cwd] | @tsv'
```

`claude-code-log` 的 README 也给了适合“喂回 LLM 分析”的紧凑 Markdown 命令：

```bash
claude-code-log transcript.jsonl --detail low --format md --compact -o session.md
```

它明确说明这种组合适合把过去 conversation 作为 LLM context。([GitHub][2])

这是我最推荐的，因为它绕开了终端控制字符问题。

## 3. 新增脚本：`scripts/save_claude_session_log.py`

```python
#!/usr/bin/env python3
"""Export a stopped/completed Claude Code background session to docs/logs/<name>.md.

This script intentionally exports from Claude Code transcript JSONL via
`claude-code-log`, rather than from `claude logs`, because terminal output can
contain ANSI cursor/control sequences.

Usage:
    python scripts/save_claude_session_log.py M7
    python scripts/save_claude_session_log.py <session-id>
"""

from __future__ import annotations

import argparse
import json
import os
import re
import shutil
import subprocess
import sys
import tempfile
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import Any, Iterable


TERMINAL_STATUSES = {"completed", "complete", "stopped", "stop"}

SECRET_PATTERNS: list[tuple[str, str]] = [
    (r"github_pat_[A-Za-z0-9_]{20,}", "GitHub fine-grained PAT"),
    (r"\bgh[opsu]_[A-Za-z0-9_]{20,}", "GitHub token"),
    (r"\bsk-ant-[A-Za-z0-9_\-]{20,}", "Anthropic API key"),
    (r"\bsk-[A-Za-z0-9_\-]{32,}", "generic sk-* API key"),
    (r"BEGIN (?:RSA |OPENSSH |EC |DSA )?PRIVATE KEY", "private key block"),
    (r"\bANTHROPIC_API_KEY\s*=\s*['\"]?[A-Za-z0-9_\-]{16,}", "Anthropic env key"),
    (r"\bOPENAI_API_KEY\s*=\s*['\"]?[A-Za-z0-9_\-]{16,}", "OpenAI env key"),
    (r"\bKAGGLE_KEY\s*=\s*['\"]?[A-Za-z0-9_\-]{8,}", "Kaggle key"),
    (r"\bSUPABASE_[A-Z0-9_]*KEY\s*=\s*['\"]?[A-Za-z0-9_\-.]{16,}", "Supabase key"),
    (r"\b(?:password|passwd|secret|token)\s*[:=]\s*['\"]?[A-Za-z0-9_\-.]{16,}", "generic secret assignment"),
]


@dataclass(frozen=True)
class Candidate:
    source: str
    job_id: str
    session_id: str
    name: str
    status: str
    cwd: str
    state_path: Path | None
    raw: dict[str, Any]


def eprint(msg: str) -> None:
    print(msg, file=sys.stderr)


def run(cmd: list[str], *, cwd: Path | None = None, timeout: int = 30) -> subprocess.CompletedProcess[str]:
    return subprocess.run(
        cmd,
        cwd=str(cwd) if cwd else None,
        text=True,
        capture_output=True,
        timeout=timeout,
        check=False,
    )


def project_root() -> Path:
    env_dir = os.environ.get("CLAUDE_PROJECT_DIR")
    if env_dir:
        return Path(env_dir).expanduser().resolve()

    proc = run(["git", "rev-parse", "--show-toplevel"], timeout=10)
    if proc.returncode == 0 and proc.stdout.strip():
        return Path(proc.stdout.strip()).resolve()

    return Path.cwd().resolve()


def claude_config_dir() -> Path:
    return Path(os.environ.get("CLAUDE_CONFIG_DIR", "~/.claude")).expanduser().resolve()


def walk_json(obj: Any) -> Iterable[Any]:
    yield obj
    if isinstance(obj, dict):
        for value in obj.values():
            yield from walk_json(value)
    elif isinstance(obj, list):
        for value in obj:
            yield from walk_json(value)


def first_value(obj: Any, keys: set[str]) -> str:
    if isinstance(obj, dict):
        for key in keys:
            value = obj.get(key)
            if value not in (None, ""):
                return str(value)

        for value in obj.values():
            found = first_value(value, keys)
            if found:
                return found

    elif isinstance(obj, list):
        for value in obj:
            found = first_value(value, keys)
            if found:
                return found

    return ""


def collect_jsonl_paths(obj: Any) -> list[Path]:
    paths: list[Path] = []
    for value in walk_json(obj):
        if isinstance(value, str) and value.endswith(".jsonl"):
            paths.append(Path(value).expanduser())
    return paths


def normalise_status(value: str) -> str:
    value = (value or "").strip().lower()
    if value in {"done", "success", "succeeded"}:
        return "completed"
    if value in {"cancelled", "canceled"}:
        return "stopped"
    return value


def related_to_project(cwd: str, root: Path) -> bool:
    if not cwd:
        return True

    try:
        p = Path(cwd).expanduser().resolve()
    except Exception:
        return True

    return p == root or root in p.parents or p in root.parents


def candidate_from_raw(
    raw: dict[str, Any],
    *,
    source: str,
    job_id: str = "",
    state_path: Path | None = None,
) -> Candidate:
    session_id = first_value(raw, {"sessionId", "session_id", "transcriptSessionId", "transcript_session_id"})
    name = first_value(raw, {"name", "displayName", "display_name", "title"})
    status = first_value(raw, {"status", "state", "lifecycleState", "lifecycle_state"})
    cwd = first_value(raw, {"cwd", "workingDirectory", "working_dir", "projectDir", "project_dir"})

    if not job_id and state_path is not None:
        # ~/.claude/jobs/<job_id>/state.json
        try:
            job_id = state_path.parent.name
        except Exception:
            job_id = ""

    return Candidate(
        source=source,
        job_id=job_id,
        session_id=session_id,
        name=name,
        status=normalise_status(status),
        cwd=cwd,
        state_path=state_path,
        raw=raw,
    )


def load_agents_from_cli(root: Path) -> list[Candidate]:
    proc = run(["claude", "agents", "--cwd", str(root), "--json"], cwd=root, timeout=20)
    if proc.returncode != 0 or not proc.stdout.strip():
        return []

    try:
        data = json.loads(proc.stdout)
    except json.JSONDecodeError:
        return []

    if not isinstance(data, list):
        return []

    out: list[Candidate] = []
    for item in data:
        if isinstance(item, dict):
            c = candidate_from_raw(item, source="claude agents --json")
            if related_to_project(c.cwd, root):
                out.append(c)
    return out


def load_agents_from_state_files(config_dir: Path, root: Path) -> list[Candidate]:
    jobs_dir = config_dir / "jobs"
    if not jobs_dir.exists():
        return []

    out: list[Candidate] = []
    for state_path in sorted(jobs_dir.glob("*/state.json")):
        try:
            raw = json.loads(state_path.read_text(encoding="utf-8"))
        except Exception:
            continue

        if not isinstance(raw, dict):
            continue

        c = candidate_from_raw(raw, source="state.json", state_path=state_path)
        if related_to_project(c.cwd, root):
            out.append(c)

    return out


def dedupe(candidates: list[Candidate]) -> list[Candidate]:
    seen: set[tuple[str, str, str]] = set()
    out: list[Candidate] = []
    for c in candidates:
        key = (c.job_id, c.session_id, c.name)
        if key in seen:
            continue
        seen.add(key)
        out.append(c)
    return out


def score_candidate(target: str, c: Candidate) -> int:
    t = target.strip()
    tl = t.lower()
    score = 0

    fields = [
        (c.job_id, 100),
        (c.session_id, 95),
        (c.name, 90),
    ]

    for value, exact_score in fields:
        if not value:
            continue
        vl = value.lower()
        if vl == tl:
            score = max(score, exact_score)
        elif vl.startswith(tl):
            score = max(score, exact_score - 10)
        elif tl in vl and exact_score == 90:
            score = max(score, 50)

    return score


def describe_candidate(c: Candidate) -> str:
    return (
        f"name={c.name or '-'} "
        f"job_id={c.job_id or '-'} "
        f"session_id={c.session_id or '-'} "
        f"status={c.status or '-'} "
        f"source={c.source}"
    )


def select_candidate(target: str, candidates: list[Candidate]) -> Candidate:
    scored = [(score_candidate(target, c), c) for c in candidates]
    scored = [(score, c) for score, c in scored if score > 0]

    if not scored:
        available = "\n".join(f"  - {describe_candidate(c)}" for c in candidates[:30])
        raise RuntimeError(
            f"No Claude background session matched {target!r}.\n"
            f"Available project sessions:\n{available or '  (none found)'}"
        )

    scored.sort(key=lambda x: x[0], reverse=True)
    best_score = scored[0][0]
    best = [c for score, c in scored if score == best_score]

    # Exact id/name match is allowed to be unique by score. Ambiguous fuzzy name
    # matches should fail loudly.
    unique_keys = {(c.job_id, c.session_id, c.name) for c in best}
    if len(unique_keys) > 1 and best_score < 90:
        choices = "\n".join(f"  - {describe_candidate(c)}" for c in best)
        raise RuntimeError(f"Ambiguous session selector {target!r}. Use an id instead.\n{choices}")

    return best[0]


def find_transcript_from_state(candidate: Candidate, config_dir: Path) -> Path | None:
    # Prefer explicit JSONL paths inside state.json.
    for path in collect_jsonl_paths(candidate.raw):
        if not path.is_absolute():
            path = (candidate.state_path.parent if candidate.state_path else config_dir) / path
        if path.exists():
            return path.resolve()

    # Then search by session id under projects.
    if candidate.session_id:
        matches = list((config_dir / "projects").glob(f"**/{candidate.session_id}.jsonl"))
        if matches:
            return matches[0].resolve()

    # Sometimes short job id is also used in paths.
    if candidate.job_id:
        matches = list((config_dir / "projects").glob(f"**/*{candidate.job_id}*.jsonl"))
        if matches:
            return matches[0].resolve()

    return None


def safe_filename(name: str) -> str:
    text = name.strip() or "claude-session"
    text = re.sub(r"[^\w.\-]+", "-", text, flags=re.UNICODE)
    text = re.sub(r"-{2,}", "-", text).strip(".-")
    return text[:120] or "claude-session"


def run_claude_code_log(transcript: Path, tmp_md: Path, detail: str) -> None:
    uvx = shutil.which("uvx")
    if not uvx:
        raise RuntimeError("uvx not found. Install uv first, then run: uvx claude-code-log@latest --help")

    attempts: list[list[str]] = []
    for fmt in ("md", "markdown"):
        for output_flag in ("-o", "--output"):
            attempts.append(
                [
                    uvx,
                    "claude-code-log@latest",
                    str(transcript),
                    "--detail",
                    detail,
                    "--format",
                    fmt,
                    "--compact",
                    output_flag,
                    str(tmp_md),
                ]
            )
        attempts.append(
            [
                uvx,
                "claude-code-log@latest",
                str(transcript),
                "--detail",
                detail,
                "--format",
                fmt,
                "--compact",
            ]
        )

    errors: list[str] = []
    for cmd in attempts:
        proc = run(cmd, timeout=180)

        if cmd[-1] == str(tmp_md):
            if proc.returncode == 0 and tmp_md.exists() and tmp_md.stat().st_size > 0:
                return
        else:
            if proc.returncode == 0 and proc.stdout.strip():
                tmp_md.write_text(proc.stdout, encoding="utf-8")
                return

        errors.append(
            "$ " + " ".join(cmd) + "\n"
            f"returncode={proc.returncode}\n"
            f"stderr={proc.stderr[-2000:]}"
        )

    raise RuntimeError("claude-code-log failed.\n\n" + "\n\n---\n\n".join(errors[-3:]))


def scan_secret_like_text(text: str) -> list[str]:
    hits: list[str] = []
    for pattern, label in SECRET_PATTERNS:
        if re.search(pattern, text, flags=re.IGNORECASE):
            hits.append(label)
    return hits


def build_header(candidate: Candidate, transcript: Path, output_path: Path) -> str:
    now = datetime.now(timezone.utc).isoformat(timespec="seconds")
    title = candidate.name or candidate.job_id or candidate.session_id or "Claude session"
    return (
        f"# Claude session log: {title}\n\n"
        f"- Exported at: `{now}`\n"
        f"- Session name: `{candidate.name or ''}`\n"
        f"- Job id: `{candidate.job_id or ''}`\n"
        f"- Session id: `{candidate.session_id or ''}`\n"
        f"- Status: `{candidate.status or ''}`\n"
        f"- Source transcript: `{transcript}`\n"
        f"- Output: `{output_path}`\n\n"
        "---\n\n"
    )


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("selector", help="Claude background session name, short job id, or session id")
    parser.add_argument("--allow-any-state", action="store_true", help="Export even if session is not completed/stopped")
    parser.add_argument("--allow-secret-like", action="store_true", help="Write even if secret-like patterns are found")
    parser.add_argument("--detail", default="low", choices=["low", "medium", "high"], help="claude-code-log detail level")
    parser.add_argument("--output-dir", default="docs/logs", help="output directory, relative to repo root")
    args = parser.parse_args()

    root = project_root()
    config_dir = claude_config_dir()

    candidates = dedupe(
        load_agents_from_cli(root)
        + load_agents_from_state_files(config_dir, root)
    )

    candidate = select_candidate(args.selector, candidates)

    if not args.allow_any_state and candidate.status not in TERMINAL_STATUSES:
        raise RuntimeError(
            f"Matched session is not stopped/completed: {describe_candidate(candidate)}\n"
            f"Stop it first with `claude stop <id>` or rerun with --allow-any-state."
        )

    transcript = find_transcript_from_state(candidate, config_dir)
    if transcript is None:
        raise RuntimeError(
            f"Could not find transcript JSONL for session: {describe_candidate(candidate)}\n"
            f"Try `claude --resume` to locate the session, or search:\n"
            f"  find {config_dir}/projects -name '*.jsonl' | grep '<session-id>'"
        )

    output_dir = (root / args.output_dir).resolve()
    output_dir.mkdir(parents=True, exist_ok=True)

    out_name = safe_filename(candidate.name or candidate.job_id or candidate.session_id or args.selector)
    output_path = output_dir / f"{out_name}.md"

    with tempfile.TemporaryDirectory(prefix="save-claude-log-") as tmp_dir_s:
        tmp_dir = Path(tmp_dir_s)
        tmp_md = tmp_dir / "session.md"

        run_claude_code_log(transcript, tmp_md, args.detail)

        body = tmp_md.read_text(encoding="utf-8", errors="replace")
        final_text = build_header(candidate, transcript, output_path) + body.rstrip() + "\n"

        hits = scan_secret_like_text(final_text)
        if hits and not args.allow_secret_like:
            labels = ", ".join(sorted(set(hits)))
            raise RuntimeError(
                f"Refusing to write {output_path}: secret-like patterns detected: {labels}.\n"
                f"Manually inspect the transcript, redact sensitive content, or rerun with --allow-secret-like."
            )

        tmp_out = output_path.with_suffix(".tmp.md")
        tmp_out.write_text(final_text, encoding="utf-8")
        tmp_out.replace(output_path)

    print(json.dumps(
        {
            "ok": True,
            "output": str(output_path.relative_to(root)),
            "matched": {
                "name": candidate.name,
                "job_id": candidate.job_id,
                "session_id": candidate.session_id,
                "status": candidate.status,
                "source": candidate.source,
            },
            "transcript": str(transcript),
        },
        ensure_ascii=False,
        indent=2,
    ))
    return 0


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except Exception as exc:
        eprint(f"ERROR: {exc}")
        raise SystemExit(1)
```

## 6. 如果 `/save-log` 没出现在 slash command 列表

在 repo 根目录重启 Claude Code session：

```bash
claude
```

然后输入 `/` 搜索 `save-log`。Claude Code 的 custom skill 目录名就是 slash command 名；`.claude/skills/save-log/SKILL.md` 应生成 `/save-log`。([Claude Code][1])

## 7. 后续可以交给 Claude Code 的实现 prompt

```text
Implement /save-log for this repository.

Goal:
Add a Claude Code project skill `/save-log <name|id>` that exports a stopped or completed Claude Code background session transcript into `docs/logs/<session-name>.md`, overwriting the previous file.

Requirements:
1. Create `.claude/skills/save-log/SKILL.md`.
2. Create `scripts/save_claude_session_log.py`.
3. Create `docs/logs/.gitkeep`.
4. Use `claude-code-log` via `uvx claude-code-log@latest` to generate clean Markdown from the transcript JSONL.
5. Do not use `claude logs` terminal output as the source.
6. Match session by name, short job id, or session id.
7. Only export sessions whose status is completed or stopped unless `--allow-any-state` is used.
8. Resolve output filename from the actual session name, sanitize it, and write `docs/logs/<name>.md`.
9. Overwrite existing output atomically.
10. Refuse to write if secret-like token/key patterns are detected, unless `--allow-secret-like` is explicitly passed.
11. Do not read `.env`, `.ssh`, `.kaggle`, or credential files.
12. Add minimal docs in the skill body or README note.

Acceptance criteria:
- `/save-log M7` runs `scripts/save_claude_session_log.py M7`.
- A stopped/completed M7 session produces `docs/logs/M7.md`.
- A running/working session fails with a clear message.
- Missing/ambiguous session names fail with a list of possible matches.
- The script respects `CLAUDE_CONFIG_DIR`.
- No secrets are committed.
```

这样实现后，你的 milestone closeout 流程可以固定为：

```text
1. milestone /goal completed
2. /save-log M7
3. review docs/logs/M7.md
4. write docs/milestones/m7/handoff.md
5. commit docs/logs/M7.md only if safe/useful
```
