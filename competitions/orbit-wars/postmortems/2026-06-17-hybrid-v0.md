# Postmortem — hybrid_v0: model candidate re-ranker (OW-P2-HYBRID-001, prompt 06)

**Date:** 2026-06-17
**Status:** integration COMPLETE + safe; model NOT promotable → reject/retrain
**Files:** `agent/main.py` (re-ranker), `agent/versions/hybrid_v0.py`, `agent/hybrid_model.py`,
`agent/hybrid_weights.json`, `models/` (trainer + real-corpus run), `core/features.py` (shared featurizer)

## What we built

A hybrid agent = v3.2 Forecast with a trained candidate scorer blended into the greedy commit order:

```
obs → v3.2 candidate generation + sizing + value sim + path-safety (unchanged)
    → _hybrid_rerank: rank-blend(v3.2 value, model score)   ← the only change
    → greedy commit → FlightOracle/ActionSanitizer emission gate (unchanged)
```

Design choices that make it safe-by-construction:
- The model only **re-orders** candidates that v3.2 already generated, sized, and path-checked. It
  never chooses an angle, a ship count, or an unsafe launch.
- `OW_HYBRID=0` (default) or any load/inference failure → plain v3.2 order. **β=0 is byte-identical to
  v3.2** (verified on a 499-turn obs replay). Strictly additive; never worse by construction.
- Online runtime is stdlib + `core` only (no numpy/torch) via `agent/hybrid_model.py`'s pure-Python
  forward — matches the offline numpy/torch path to 3e-16. p99 44 ms/turn (< 50 ms local target).
- One feature source of truth (`core.features.feature_vector`) shared by trainer and runtime
  (bit-identical on 5000 rows) — no train/serve skew.

## The model

Real ladder corpus: 310 episodes (156 2p + 154 4p) from our submissions 53582503 (μ→1103) / 53730511,
fetched read-only from the public episode store. 2.48M candidates, 4786 teacher-positives. MLP
24→128→64→1, BCE on `teacher_selected`. Offline valid **AUC 0.882** (2p 0.875 / 4p 0.886), recall@5
0.59. Card: `models/reports/model_card_20260617-cs-ladder310.md`.

## What happened (arena A/B, 240 games/cell)

| matchup | control (v3.2) | hybrid | result |
|---|---|---|---|
| vs evogen1093 (μ1093) | 13.8% | 13.8–14.6% | **flat — strong-tier cliff intact** |
| vs kuni05 (μ1240) | 0.8% | 0.8% | crushed (avg score 17 vs 2315) |
| vs v3.2 (near-mirror) | 33% (80 ties) | 46% but 111W/129L | tie-conversion, net ≈even/behind |
| vs pub_tactical (weak) | 97.9% | 97.9% | non-regression ✓ |
| 4p FFA avg_rank | 1.77/4 | 1.77/4 | non-regression ✓ |

AUC 0.88 offline → **zero strong-tier improvement** online. The +7pt strong-tier gate (VALIDATION #3)
is not met.

## Why (root cause)

1. **Teacher ceiling.** The imitation target is similar-skill ladder play (~μ1077), not strong-tier.
   The model learns "what a mid-ladder player launches", which is exactly what v3.2 already does — so
   re-ranking toward it adds nothing against μ1093+ opponents. Third confirmation of the imitation
   lesson (T12 BC: recall 0.387 / arena 0%; local-data run; now real-data run).
2. **The gap is strategic, not selection.** kuni05 beats v3.2 0.8% with a ~135× score margin — that is
   a different *strategy*, not a better ranking of v3.2's candidate set. A re-ranker over v3.2's own
   candidates cannot manufacture strategy v3.2 never generates (consistent with B6: 13 single-mechanism
   levers refuted).
3. **Mirror tie-conversion is not a win.** The +12.9pt "win%" vs frozen v3.2 is the B2 mirror-null
   artifact: the re-ranker breaks symmetry so draws become decisive, but W≈L and our avg score is lower.

## Decision

**Reject for promotion; keep the integration.** `hybrid_v0` is NOT submitted to the ladder
(`live/last_eval.json` `submit_ready=false`). The infrastructure (safe, inert at β=0, non-regressive,
fast, fallback-clean) stays as the substrate for a better model.

## Next (follow-up task)

To have a chance at the cliff, the corpus needs **genuine strong-tier teachers**, not our own
mid-ladder episodes:
- discover top-player submission ids (multifocus / real kuni05 / μ>1240 leaders) and fetch THEIR
  episodes; retrain winner-seat / top-player-only;
- consider moving past pure imitation — value/outcome distillation, or a search-based policy that can
  generate strategy v3.2 lacks;
- re-run this exact A/B harness (`OW_HYBRID` vs frozen v3.2 + evogen + kuni05) as the gate.
